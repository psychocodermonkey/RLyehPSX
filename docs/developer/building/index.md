# Building

Build from the repository root using the guide for your host platform. The dependency scripts install third-party components into `deps/`; the CMake presets configure the application against that local tree.

- [macOS source build](macos.md)
- [Linux source build](linux.md)
- [CMake presets](cmake_presets.md): available configurations, usage, and maintenance.
- [Windows build migration inventory](windows_build_documentation.md): reference material for future Windows CMake/Ninja work. It is not a supported build guide.
